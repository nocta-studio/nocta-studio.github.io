# nocta-studio.github.io

Static GitHub Pages site for Nocta Studio. It hosts the public pages the Google OAuth app "Nocta Backup" needs for production publishing.

## Pages
- `index.html`: app home page
- `privacy.html`: privacy policy
- `terms.html`: terms of service

## Notes
- Plain HTML, no build step. Changes pushed to the default branch are served by GitHub Pages.
- Do not remove or rename these pages while the OAuth app is in production: Google's branding settings link to them.
